Portafolio Profesional - Ingeniería de Sistemas
Sitio web modular desarrollado como proyecto académico. Presenta una estructura de múltiples páginas unificadas mediante una barra de navegación adaptable, aplicando buenas prácticas de desarrollo frontend y diseño limpio.

Tecnologías y Herramientas Utilizadas
HTML5: Estructura semántica dividida en seis páginas independientes (contacto.html, perfil.html, experiencia.html, formacion.html, proyectos.html, referencias.html).

CSS3 y Bootstrap 5: Estilos personalizados en un archivo central (css/styles.css), combinados con componentes visuales variados (tarjetas, tablas, listas, insignias y formularios) para asegurar que cada sección mantenga un formato propio.

JavaScript (DOM): Lógica interactiva centralizada en (js/main.js) que implementa manipulación avanzada del DOM:

Modificación de contenido dinámico mediante textContent.

Alteración de estilos en tiempo de ejecución con .style.

Gestión de clases dinámicas usando classList.toggle.

Consulta y modificación de atributos con setAttribute.

Escucha de eventos del usuario a través de addEventListener para clics, desplazamiento del cursor y envío de formularios.

Creación, inserción y eliminación de elementos en tiempo real mediante createElement, appendChild y .remove().

Recursos multimedia: Gestión de archivos gráficos centralizados en la carpeta img/ (perfil.jpg, proyecto1.jpg, proyecto2.jpg, proyecto3.jpg).
